# 出産・子育て「もらえる・戻ってくる」完全アクションプラン(吹田市版)

大阪府吹田市在住・2026年8月12日出産予定の家庭向けに、出産支援金・子育て支援・税金対策を
時系列のチェックリストとしてまとめた資料です。

## ファイル

| ファイル | 内容 |
|---|---|
| `出産子育ておかね完全アクションプラン_吹田市版.pdf` | 配布用PDF(全9ページ・申請先URL付き) |
| `plan.html` | PDFの生成元HTML(編集後、ChromiumのPrint to PDFで再生成可能) |

## 構成

1. 表紙・もらえるお金の目安(モデルケースで約350万円)
2. 全体タイムライン(2026年7月〜2027年3月)
3. STEP1 出産前(今すぐ〜8月上旬)
4. STEP2 出産直後(生後15日以内が勝負)
5. STEP3 産後2か月〜1歳(給付金の受取りと保育園申込)
6. STEP4 税金で取り戻す(年末調整・確定申告)
7. もらえるお金の全体像(金額試算・申請漏れで失う額)
8. 申請先・窓口・URL完全リスト
9. 今後の制度変更と注意事項

## PDFの再生成方法

```bash
chromium --headless --no-pdf-header-footer \
  --print-to-pdf=出産子育ておかね完全アクションプラン_吹田市版.pdf plan.html
```

制度情報は2026年7月2日時点の公開情報(吹田市・こども家庭庁・厚生労働省・協会けんぽ・
日本年金機構・国税庁)に基づきます。最終確認は資料内の公式URLで行ってください。
